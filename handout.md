# Инструкция для слушателя — твой первый сайт за 10 минут

Не бойся. Тебе не нужно уметь программировать. Ты будешь **ставить задачи**, а код напишет агент. Поехали.

## Что тебе понадобится

**Приходишь с этим (сделано до занятия):**

- подписка Claude (минимум Pro) и аккаунт GitHub;
- рабочий VPN: claude.ai открывается без ошибки региона;
- установленные **VS Code** и **Handy** (голосовой ввод, можно диктовать промпты).

**На занятии настраиваем:**

- расширения Claude Code и Claude Usage Bar (показывает, сколько лимита осталось) внутри VS Code и вход в Claude;
- Handy: модель, горячая клавиша, язык;
- Git + GitHub CLI в конце занятия, их ставит сам агент, см. [`github-setup.md`](github-setup.md).

> Инструкция «с чем прийти» прислана отдельно перед курсом. Если что-то из первого
> списка не готово, скажи преподавателю в начале занятия, а не в середине.

## Шаг 1. Персонаж

Сегодня ты ведёшь **выдуманного персонажа**, не себя — например, Королеву
Елизавету II, Скруджа Макдака или Супермена. Персонажей около двадцати, агент
сам предложит на выбор несколько штук на шаге 2, выбирать заранее не нужно.
Внутри папки каждого персонажа:

```
про-меня.md   — кто это, характер, био
проекты.md    — чем занимается, достижения
факты.md      — смешные детали
images/       — тематические картинки персонажа
```

**⚠️ Страницу про себя настоящего делаешь дома, после занятия** — это домашнее
задание, см. в самом низу.

## Шаг 2. Забери папку персонажа

Создай у себя папку `work` — общий дом для всех твоих проектов курса, назвать
можно с любым регистром (`work`, `Work` — не важно), лежать может где угодно,
где тебе удобно. Открой её в VS Code (`File → Open Folder…`), запусти Claude
Code и отправь промпт [`get-character.md`](prompts/get-character.md) как
есть, ничего в нём подставлять не нужно. **Агент сам** найдёт папку `work`,
предложит на выбор персонажей и скачает выбранного — в новую подпапку
`work/Persona/`. Уже на этом шаге видно: ты просто попросил — он сделал.

## Шаг 3. Собери страницу

Возьми промпт [`persona-page.md`](prompts/persona-page.md), скопируй блок и отправь
(или надиктуй голосом через Handy). Агент прочитает файлы, соберёт страницу и
**откроет её в браузере**. Вот он, момент «ого, я сделал сайт».

## Шаг 4. Поиграй

Скажи агенту своими словами, что поменять: «сделай теплее», «добавь цитату»,
«крупнее заголовок». Смотри, как страница меняется от твоих слов.

## Шаг 5. ⭐ Поставь свою картинку (бонус для «вау»)

Картинки подобраны автоматически — дёшево, быстро, свободные лицензии, минимум
ручной курации, — поэтому под твою конкретную страницу могут подойти не идеально.
Это нормально: так выглядит результат дешёвой автоматизации, и сейчас у тебя есть
шанс её улучшить. Хочешь усилить эффект — сходи в интернет, найди картинку получше
(своё фото или кадр в духе персонажа) и положи её в `work/Persona/images/` — рядом с
уже лежащими картинками персонажа. Потом попроси агента: «сделай
вот эту картинку главной». Страница станет по-настоящему твоей — а ты попутно
научишься подсовывать агенту свои файлы.

## Шаг 6. Полюбуйся результатом

Твоя страница открылась в браузере — это и есть первый «вау». Пока она живёт
локально, у тебя на компьютере. **Выложим её в интернет на занятии 2** — и тогда
появится живая ссылка, которую можно скинуть друзьям. На первом занятии не
спешим: главное — почувствовать, что ты собрал сайт своими словами.

## Шаг 7. Подключи GitHub (готовим выход в интернет)

Чтобы на следующем занятии сайт уехал в интернет без заминок, подготовим
инструменты уже сегодня: ставим **Git** и **GitHub CLI** и логинимся. Ставить
будет сам агент — тебе не придётся разбираться, чем отличается установка на
Windows, macOS и Linux.

👉 Отправь агенту промпт [`github-cli-setup.md`](prompts/github-cli-setup.md) как есть:
он поставит Git и GitHub CLI, залогинит агента в GitHub и покажет, что всё работает.
Второй логин, для самого VS Code, и что делать, если не вышло, в [`github-setup.md`](github-setup.md).

> ⚠️ **Не успел на занятии, сделай дома до занятия 2.** Без GitHub CLI агент не сможет
> выложить твой сайт в интернет, и на занятии 2 ты будешь догонять, пока группа идёт дальше.

> Владельцам **Windows** этот шаг особенно важен: без Git агент выполняет команды
> по-другому, чем показано на экране у преподавателя.

## Что дальше по курсу

| Занятие | Что делаешь |
|---------|-------------|
| 1 | Забираешь персонажа, собираешь страницу Persona (открывается локально), ставишь GitHub CLI |

| 3 | MCP: агент выходит в браузер и подбирает идею проекта под тебя |
| 4 | Агенты, скиллы, Superpowers и лендинг твоей идеи в интернете |

| 6 | Ревью, свои команды, хуки и дизайн для твоих страниц |

| 8 | Cowork, показ проектов и дорожная карта после курса |

Раздатка каждого занятия лежит в своём репозитории: `github.com/ahtlv/claude-course-lesson-N`,
где N это номер занятия. Ссылку на очередной дам на занятии.

## Домашнее задание после занятия 1

**Обязательно: собери страницу Persona целиком про себя.** На занятии ты тренировался
на персонаже — дома перепиши файлы в `work/Persona/` (`про-меня.md`, `проекты.md`,
`факты.md`) под себя настоящего и замени главную картинку на своё фото (или похожий
кадр) в `work/Persona/images/`. Прогони тот же промпт
[`persona-page.md`](prompts/persona-page.md) ещё раз — на этот раз
`work/Persona/index.html` должен получиться полностью про тебя.

Это не только ради геймификации: эти файлы станут основой контекст-профиля
(занятие 2) и матча с идеями (занятие 3) — чем честнее и подробнее о себе,
тем точнее выйдет идея твоего будущего проекта.

**Покажи группе:** до занятия 2 выложи скриншот своей страницы Persona в чат
курса отдельным постом. Смотреть чужие работы полезно не меньше, чем делать свою.

Это только начало — к концу курса у тебя будет два живых сайта в интернете,
собранных твоими руками (ну, почти твоими).

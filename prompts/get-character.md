# Забери своего персонажа (занятие 1)

**Когда:** самый первый шаг, до всего остального.
**Что делает:** агент сам находит твою папку `work` (общий дом для всех проектов
курса) — по открытой в VS Code папке или поиском по компьютеру, а если не находит,
спрашивает тебя явно. Дальше создаёт внутри неё `Persona/`, узнаёт, какого персонажа
ты выбрал, и скачивает его файлы — руками ничего создавать и качать не нужно.
**Как использовать:** если у тебя уже есть папка `work` — открой её в VS Code (`File →
Open Folder…`); если ещё нет — можно открыть любую папку или не открывать ничего,
агент разберётся сам. Запусти Claude Code и отправь промпт ниже как есть, ничего в
нём подставлять не нужно — ссылка на репозиторий уже встроена. Дальше просто отвечай
на вопросы агента по ходу.

> Список персонажей (и их короткие имена-папки) — в README этого репозитория.
> Называть персонажа заранее не нужно — агент сам покажет варианты на выбор и спросит.

```text
Выполни по порядку, не пропуская шаги и не забегая вперёд:

1. Найди мою рабочую папку `work` — регистр не важен, подходит `work`, `Work`,
   `WORK` и любой другой вариант написания:
   - если папка, открытая сейчас в VS Code, уже называется `work` в любом регистре
     (или лежит внутри такой папки) — используй её, ничего не спрашивай;
   - иначе поищи такую папку у меня на компьютере без учёта регистра (в первую
     очередь в домашней папке и её подпапках, не по всему диску):
     - нашёл ровно одну — используй её, ничего не спрашивай;
     - нашёл несколько — покажи список найденных путей и спроси, какую использовать;
     - не нашёл ни одной — спроси меня, где она лежит или где её создать.
   Дождись ответа, если он нужен, и только после этого работай дальше внутри `work/`.

2. Внутри `work/` создай подпапку `Persona/`, если её там ещё нет.

3. Склонируй во временную папку репозиторий https://github.com/ahtlv/claude-course-lesson-1 — персонажей там около
   двадцати, полный список подпапок возьми из README репозитория или прямо из
   склонированной папки.

4. Предложи мне на выбор несколько персонажей — столько, сколько помещается в твоём
   диалоговом окне выбора (обычно не больше четырёх), выбранных СЛУЧАЙНО из полного
   списка, а не первые по порядку. Дай также возможность назвать своего персонажа,
   если я хочу не из предложенных. Дождись ответа.

5. Перенеси в `work/Persona/` содержимое ТОЛЬКО подпапки выбранного персонажа.
   Временную папку с остальным репозиторием удали.

В итоге в work/Persona/ должна получиться такая структура:

про-меня.md
проекты.md
факты.md
images/
  ...несколько картинок...
  CREDITS.md

Когда закончишь — покажи дерево того, что оказалось в work/Persona/.
```

Когда файлы окажутся на месте — переходи к промпту [`persona-page.md`](persona-page.md)
и собери свою страницу.

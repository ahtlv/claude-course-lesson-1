# Git и GitHub CLI: установка и вход (занятие 1)

**Когда:** в конце занятия 1, после того как страница Persona открылась в браузере. Не успели
на занятии, сделай дома до занятия 2: без этого шага сайт в интернет не уедет.
**Что делает:** агент сам проверяет, стоят ли у тебя `git` и GitHub CLI (`gh`), ставит
недостающее под твою систему (Windows, macOS, Linux), логинит агента в GitHub и показывает,
что всё работает.
**Как использовать:** в VS Code открыта папка `work`, отправь Claude Code текст из блока ниже
как есть. Дальше отвечай на вопросы агента. Когда откроется браузер, подтверди вход на GitHub.

> Зачем это и что делать, если не вышло, подробно в [`../github-setup.md`](../github-setup.md).
> Там же второй логин, для самого редактора VS Code: его делаешь руками, пара кликов.

```text
Подготовь мой компьютер к работе с GitHub. Выполни по порядку:

1. Проверь, установлены ли у меня git и GitHub CLI (gh).
   Если чего-то нет, определи мою операционную систему и установи
   подходящим для неё способом. Если система попросит пароль
   администратора, предупреди меня.

2. Запусти gh auth login, чтобы я авторизовался на GitHub:
   GitHub.com, протокол HTTPS, вход через браузер. Если нужен
   одноразовый код, покажи его мне крупно и дождись, пока я подтвержу
   вход в браузере.

3. После авторизации настрой git на работу с GitHub через gh
   (gh auth setup-git).

4. В конце покажи версии git и gh и мой статус авторизации на GitHub.

Если на каком-то шаге ошибка, не иди дальше: объясни простыми словами,
что случилось, и предложи, что сделать.
```

Должно получиться примерно так:

```
git version 2.51.0
gh version 2.89.0
✓ Logged in to github.com account твой-ник
```

Видишь свой ник в последней строке, значит всё готово. «Команда не найдена», хотя только что
ставили? Перезапусти VS Code целиком и отправь промпт ещё раз. На Windows после установки Git
перезапуск обязателен.
